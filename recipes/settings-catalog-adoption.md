# Bounded Settings Catalog reference path

**Decision:** use Deployment Theory's typed resource at v1.0.0 (`1718c946b3ae111bb44c7c1d925b3e35b708cb0a`) as an **offline reference candidate**, not a production recommendation/approval. It exposes a bare-ID importer, explicit settings Read and assignment construction. The exact resource name and schema come from `resource.go` at the pinned revision. Microsoft `msgraph` v0.5.0 (`058dd7651d92d741d48e868d815826edec669229`) remains a comparison source: its generic collection/$ref interface does not supply proof of Intune assign-action ownership. No silent provider substitution is allowed in a real repository.

Scope: plain Windows10 + MDM Settings Catalog policy, templateReference templateId empty/templateFamily none, explicit settings and complete group assignments, no secrets, referenced groups/filters/tags externally owned. Definitions in the synthetic fixture are API-shaped examples, not proof of live setting availability. Unsupported platform, template, secret, assignment kind or polymorph blocks active output. Full helper behavior is in `reference/core.py`; independent oracle in `reference/invariants.py`.

Complete HCL and import blocks are under `examples/supported/expected/project/components/terraform/intune-reference/`. Settings is a JSON string wrapping a settings array. Group assignments use `type`, `group_id`, `filter_type`, optional `filter_id`. Import ID is the existing policy UUID, NOT a display name or a group `$ref` URL. Policy and assignment ownership remain together; referenced groups are not generated as owned resources. CLI import cards and declarative imports are alternatives, not instructions to run both.

`resource.go::ImportState` only attaches the ID. `crud.go::Read` gets base policy, settings and assignments; `Update` issues PUT then POST assign. Therefore any unexpected update in this typed path remains potentially remote-mutating. It cannot be waved through using msgraph's unrelated state-only `$ref` special case.

Separate authorized qualification: inspect exact provider schema and dependency closure; initialize only in a disposable approved tenant/state; obtain complete baseline; import bare ID; compare refreshed policy identity/settings/assignment tuples with baseline; inspect JSON plan and capture permitted API traces. Reject creates/deletes/replacements. Classify every update by pinned code path and independently observed effects. Require unchanged service read-back and preserved assignments before adoption completion. Do not mutate raw state or use broad ignore_changes to force a no-op.

Known qualification blockers: assignment pagination; common settings serializer coverage; filter default/validator interaction; source comments incorrectly calling separate updates atomic; potential partial-create failure before state persistence; template policies outside this slice; debug logging may include request bodies. APIs are beta; organization approval and OpenTofu/provider execution are unperformed.

For incomplete input the reference writes only `.tf.txt` review text, unresolved pointers, and `BLOCKED.json`. It emits no active import block or command card. Supported active HCL still has default-false live-qualification acknowledgement; that precondition is an aid, NOT an authorization boundary and NOT a guarantee providers will not read before it fails.
