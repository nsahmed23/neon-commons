## Remaining product work (not represented as repaired bugs)

1. Full effective Atmos identity is still absent. The literal adapter does not evaluate logical stack naming, config layers outside the repository, templating/functions, auth, backends, state/workspace identity, or environment/CLI overrides. Those are intentionally blocked or unknown, not qualified production context.
2. Cross-stack/context dependency resolution remains unknown; matching physical manifest names is not logical stack identity. A qualified effective-context adapter must provide explicit identity and provenance before those relationships become execution dependencies.
3. The graph remains an offline evidence model. It does not establish authenticated cloud/tenant/principal identity, fresh service state, ownership eligibility, live group membership, filter impact or adoption safety. These need separately qualified collectors and service experiments.
4. No scheduler or cloud mutation runner is enabled. Adding action/judge edges does not supply guarded execution, concurrency, state locking or partial-failure reconciliation. The LLM judge must remain advisory to deterministic validity and execution gates.
5. Existing literal native parity receipts cover narrow vars fixtures only. The broader supported resolver surface still benefits from a qualified differential corpus for command, providers, settings, metadata and discovery semantics; this audit found no new resolver merge counterexample but does not turn code review into a proof.
6. Source byte hashes and graph digests are reproducible integrity checks. They are not signed producer attestations or authenticated capture evidence. The new ontology checks reject contradictions without claiming to authenticate source truth.

Assessment: the local relationship layer is more reliable after these repairs, but the intended production brownfield adoption plugin remains an alpha. Substantial implementation beyond testing is required; a percentage without explicit product scope would be misleading.
