The foreign-nextLink test proves an attempted URL only. It does **not** establish credential leakage: the actual authentication provider's allowed-host behavior is outside that fake-adapter test. A populated local JSON document or successful fixture receipt cannot authenticate a target.

## Smallest safe product decision

Keep production candidates inactive and provider qualification false. Do not alter immutable IDs, strip observation fields, normalize away null/order differences, or weaken the independent capture gate to make this provider pass. The mapper cannot repair a provider refresh helper that accepts 403 responses or truncates a later page.

The supplied local helper patch now has passing source tests for explicit status validation, bounded same-origin/path paging, initial query preservation and malformed-page rejection. A provider update/fork still needs complete assignment paging and refreshed-state semantic equivalence tests. Each change needs new provider source identity, schema/RPC validation, real import/ordinary-plan/refresh-plan tests and authorized service experiments. Passing a patched source helper alone would still not qualify the resource lifecycle.
