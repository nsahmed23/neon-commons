# Source and skill consideration boundary

Pinned acquisition enumerated SKILL.md entries in 21 named repository trees. Every discovered entry has an individual disposition. Exact-byte mirrors are grouped by SHA-256; different bytes are not automatically deduplicated. The installed skill inventory is a separate catalog.

Acquisition is not adoption: `instruction_review` distinguishes complete selected instructions/references read in this phase from metadata triage. Unread applicable skills remain deferred. They provide no execution authority. No catalog installer, hook, or copied executable was installed by this inventory.

Current Atmos catalog instructions are newer than the pinned Atmos 1.199.0 execution profile. The native adapter admits only the independently parsed literal subset, explicitly disables functions/templates, sanitizes ambient configuration, denies sockets, and compares actual native vars/env/settings/providers, physical manifest, logical stack and implementation. Newer flags/features described by current catalogs are not silently enabled. Complete `atmos-stacks` and `atmos-introspection` instruction files plus their three references were read. The measured native command confirms the actual pinned flag surface. `tenant` context remains a descriptive value, not Entra authentication.

The broader ecosystems include cloud services and offensive/security tooling irrelevant to this local Intune builder. Exclusions are scope decisions, not security endorsements. Deferred compatibility/license/dependency checks remain gaps before reuse. Complete arbitrary Atmos config layers, remote imports, dynamic YAML, hooks, workflows, backend auth transforms and unreviewed providers are not admitted by the bounded native adapter.

Source-byte receipts include Git commit/blob identity and SHA-256. No entire-catalog semantic audit, complete external reference closure or universal skill discovery is claimed. Tree truncation and failed transfers are visible. Catalog bytes reside in the separately preserved source acquisition tree during this task; the distributable inventory carries the immutable source URLs and replay script. Selected security source bundles and provider/lab sources are retained in the source repository under their own licenses.

The final acquired-file integrity check covers 5,366 raw files: every byte sequence matches its pinned Git blob and has a SHA-256 receipt. The separately delivered Source_Catalog_Evidence.zip preserves these review inputs. Source copies are not runtime dependencies. Current dispositions: 1,469 excluded, 143 deferred, 15 reference-only and 5 adapted. Two selected Microsoft Python identity/storage instructions and their four companion references were read in full; exact hashes and restrictions are in protected-source-ledger.json.
