# Offline diagnostic materials and collector boundary

A complete synthetic input and expected analysis are in examples/diagnostics/. The schema tracks stage, status, time, source pointer, coverage and capture limitations. Default mode consumes existing minimized artifacts only. Nothing installs, authenticates, captures logs or inspects a real device.

Use separate observed facts, hypotheses, proposed tests and conclusions. Prioritize the smallest discriminating signal, not maximal log collection. Preserve raw evidence only in its approved restricted store; derivative records use stable pseudonyms and a separately protected identity mapping. Inspect records locally before model exposure. The reference redaction function is narrow and is not a guarantee that logs/command lines or unknown fields contain no secrets.

PowerStacks remains a method/reference lead, not a bundled collector. Its earlier observed auto-install and escalation behaviors must be rechecked from the pinned script before adaptation (source-lock and citation-repair ledger). No claims that a particular timer/event applies to all builds. Collect OS/IME version, logging enablement/access/window/truncation/clock uncertainty before treating event absence as meaningful. Binary analysis remains an explicitly authorized lab specialization.
